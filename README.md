Developed a comprehensive data preprocessing, exploratory data analysis, and multi-method feature selection pipeline in R for stroke risk prediction—encompassing rigorous missing value imputation, outlier handling via Winsorization, binary and one-hot categorical encoding, skewness correction with logarithmic and square root transformations, Min-Max scaling, and Z-score normalization, followed by advanced feature evaluation utilizing correlation analysis, variance thresholds, ANOVA F-scores, and mutual information.
